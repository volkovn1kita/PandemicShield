Без власної лабораторії головне вузьке місце — дані. Етап 4 робить відкриті дані NCBI першоджерелом:
їх можна масово імпортувати, побачити картину по країні, визначити, чий це штам, і передати результат далі.

## 1. Масовий імпорт з NCBI

**Що:** кнопка «Імпорт з NCBI» на сторінці «Запуски». На вхід — до 500 номерів або ZIP-архів NCBI Datasets.

| Що вставили | Що стається |
|---|---|
| Номери послідовностей (`OQ291490.1`, `MN908947.3`, `NC_045512.2`) з типом «Вірус» | E-utilities `efetch` пачками по 200 → **один запуск** з усіма геномами, як файл з кількома записами. Nextclade порівнює їх в одній таблиці |
| Номери збірок (`GCA_…`, `GCF_…`) або хромосом (`CP…`) з типом «Бактерія» | NCBI Datasets API v2 → **окремий запуск на кожну збірку**, бо кожна — це окремий ізолят |
| ZIP з NCBI Virus / NCBI Datasets | Той самий розподіл: вірусний `genomic.fna` → один запуск; теки `GCA_…` → запуск на теку |

**Чому так:**
- Імпорт іде через той самий `AnalysisSubmitter`, що й ручне завантаження. Отже, імпортовані дані проходять увесь конвеєр:
  мотиви ORF, Nextclade, AMRFinderPlus, MLST.
- Вид для AMRFinderPlus береться з метаданих NCBI («Klebsiella pneumoniae subsp. pneumoniae HS11286» → `Klebsiella_pneumoniae`),
  якщо його не задано явно. Без виду AMRFinderPlus не шукає точкових мутацій.
- Номер, якого немає в NCBI, не зупиняє решту: він записується в помилки пакета.
  Datasets на неіснуючу збірку відповідає 200 і обірваним ZIP без каталогу — це розпізнається окремо.
- NCBI дозволяє 3 запити на секунду без ключа і 10 з ключем (`NCBI_API_KEY` у `docker-compose.yaml`). Клієнт тримає цей темп.
- Імпорт виконується у фоні (черга `import_jobs`, обробник усередині API). Пакет, перерваний перезапуском API,
  позначається як невдалий: так ті самі дані не завантажуються двічі.

**Перевірено:** 3 з 4 номерів SARS-CoV-2 (неіснуючий записано як помилку), 2 з 3 збірок Klebsiella з автовизначенням виду,
обидва типи архівів.

## 2. Нагляд за резистентністю (сторінка «Нагляд AMR»)

**Що:** NCBI Pathogen Detection уже прогнав AMRFinderPlus для сотень тисяч ізолятів. Кнопка «Оновити з NCBI»
бере найновіший файл `PDG….amr.metadata.tsv` обраної групи бактерій і лишає ізоляти з обраних країн (за замовчуванням — Україна).

| Група | Розмір файлу |
|---|---|
| Enterobacter hormaechei | 14 МБ |
| Pseudomonas aeruginosa, Acinetobacter, Enterococcus faecium | 56–60 МБ |
| Staphylococcus aureus, Klebsiella | 157–185 МБ |
| Escherichia coli / Shigella, Salmonella | 527–832 МБ |

**Як улаштовано:**
- Файл читається потоком, рядок за рядком: пам'ять не залежить від розміру. Прогрес оновлюється за таймером,
  бо в 800-мегабайтному файлі збіги з Україною трапляються рідко.
- У файлі є лише символи генів (`blaOXA-48,gyrA_S83I=POINT`). Клас антибіотиків береться з бази AMRFinderPlus,
  яка вже лежить в образі воркера: алелі (`AMRProt.fa`), точкові мутації (`AMRProt-mutation.tsv`, `AMR_DNA-*.tsv`),
  родини (`fam.tsv`). Тому оновлення виконує воркер AMRFinderPlus, на окремому каналі, щоб не затримувати аналіз збірок.
- **Карбапенемаза ≠ стійкість до карбапенемів.** Мутація порину `ompK36_D135DGD` теж має підклас CARBAPENEM, але це не фермент:
  вона лише звужує «вхід» антибіотика в клітину. Карбапенемазами рахуються лише гени (не POINT). Закріплено тестом.
- Лабораторії пишуть ті самі міста по-різному (Vinnitsa і Vinnytsia): регіони зводяться до офіційної транслітерації.
- Кнопка «Аналізувати» біля ізоляту імпортує його збірку (п. 1) і проганяє власні AMRFinderPlus та MLST.

**Що показує (Klebsiella, Україна, PDG000000012.2562):** 238 ізолятів (2014–2025, переважно 2022–2023, рани),
**86% з карбапенемазою**: NDM — 136, OXA-48 — 99, KPC — 34. Для порівняння, у Польщі (512 ізолятів) домінує VIM.

> Обмеження, яке написано й під графіками: це ізоляти, які лабораторії **самі вирішили опублікувати**.
> Вибірка не репрезентативна для країни, а ген — прогноз, не антибіотикограма.

Оформлення графіків — за [`DESIGN.md`](DESIGN.md) і правилами візуалізації: стовпчики не ширші за 24 px з проміжком 2 px,
одна вісь, легенда для двох серій, підказки при наведенні, таблиця з тими самими даними. Пару кольорів
«карбапенемаза / решта» перевірено на розрізнення при дальтонізмі (токени `chartAlert`, `chartRest` у `theme.dart`).

## 3. MLST: тип штаму

**Навіщо:** ген показує, *що* є в бактерії; ST (sequence type) — *чий це штам*. Той самий ST у різних шпиталях — можлива
спільна лінія або спалах. У даних Pathogen Detection колонка `computed_types` для українських ізолятів порожня,
тож ST треба рахувати самим.

**Як:** новий воркер `PandemicShield.Mlst` в образі `staphb/mlst:2.35.0` (mlst Торстена Земанна, BLAST і схеми PubMLST
всередині, працює офлайн). Кожен бактеріальний запуск отримує завдання MLST паралельно з AMRFinderPlus.

- Схема береться з виду AMRFinderPlus (`Klebsiella_pneumoniae` → `klebsiella`). Автовизначення небезпечне: збірка Klebsiella
  дає однаковий бал і в схемі E. coli (mlst сам попереджає `klebsiella(11)==ecoli_achtman_4(14464)`).
- Нові правила `st:klebsiella/147` (або `st:147` для будь-якої схеми — номери ST повторюються між схемами).
  Стартові: K. pneumoniae ST147, ST395, ST307, ST23 (гіпервірулентний), ST258; E. coli ST131; A. baumannii ST2.
- Пошук «ST147» у полі пошуку генів знаходить той самий штам у всіх запусках.

**Що вийшло на справжніх даних:**

| Збірка | ST | Що це означає |
|---|---|---|
| GCF_000240185.1 (HS11286) | ST11 | Збігається з публікацією — контроль |
| GCA_009887825.1 (Україна, 2017, рана, OXA-48) | **ST395** | Клон високого ризику, поширений у Східній Європі; спрацювало правило |
| GCA_059491835.1 (Україна, 2025, рана) | **ST23** | **Гіпервірулентний** клон з NDM-1 + OXA-48 і мутаціями стійкості до колістину (`mgrB`, `pmrB`) — «конвергентний» штам |
| `kpneumoniae-demo.fasta` | — | Синтетична збірка: генів схеми немає, чесне «не визначено» |

## 4. Звіт по зразку (PDF / CSV)

Кнопка «Звіт» на сторінці запуску. API: `GET /api/runs/{id}/report.pdf?lang=uk|en` і `GET /api/runs/{id}/report.csv`.

- **PDF** — передати результат далі. Що за зразок і звідки, версії (тег набору даних Nextclade, база AMRFinderPlus, mlst),
  геноми або прогнозована стійкість, тип штаму, усі сповіщення, дисклеймер «не медичний виріб».
  Шрифти IBM Plex з кирилицею вбудовано (OFL). Бібліотека — QuestPDF за ліцензією Community
  (безкоштовна для open-source і невеликих організацій).
- **CSV** — для Excel, R, pandas. Колонки англійською й стабільні, числа з крапкою, UTF-8 з BOM (інакше Excel псує кирилицю).
  Рядок на геном (віруси), на знахідку з ST у кожному рядку (бактерії) або на сповіщення (лише мотиви ORF).
